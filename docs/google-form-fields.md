# 表單欄位對照表：\*體重維持紀錄

`tools/create-google-form.gs` 的 `itemSpecs()` 是**唯一的欄位定義來源**。
本檔是給人看的對照表，改欄位時兩邊都要更新。

## 欄位與回覆試算表欄位對應

表單題目順序＝回覆試算表欄位順序。A 欄是時間戳記，故第 n 題落在第 n+1 欄。

| 欄 | 題目 | 型態 | 選項 |
|---|---|---|---|
| A | 時間戳記 | 自動 | — |
| B | 姓名 | 簡答 | — |
| C | 西元出生年 | 簡答 | — |
| D | 體重(kg) | 簡答 | — |
| E | 身高(cm) | 簡答 | — |
| F | BMI分級 | 單選 | 小於24但腰圍超標／24-27／27-30／30-35／大於35 |
| G | 腰圍(cm) | 簡答 | —（可留空） |
| H | 與前次相比體重變化 | 單選 | 下降／無變化／上升 |
| I | 飲食習慣 | 複選 | 外食居多／含糖飲料／偏好肉類／偏好飯、麵食類／甜點、餅乾類／宵夜／經常飲酒／其他 |
| J | 運動頻率 | 單選 | 無／有 |
| K | 每週運動頻率 | 單選 | 1-3次／3-5次／每天／假日／**無** |
| L | 每次運動時間 | 單選 | 30分鐘以內／30至60分鐘／60分鐘以上／**無** |
| M | 運動類型 | 複選 | 走路／快走／慢跑／重訓／瑜珈／球類／腳踏車／游泳／核心訓練／其他／**無** |
| N | 目前用藥 | 單選 | 無用藥／生活型態、Mounjaro、Ozempic、Wegovy、Saxenda、Rybelsus、Contrave、Xenical、Jardiance、Acarbose、併用／轉換兩種 |
| O | 藥物劑量 | 簡答 | 由工具端下拉產生固定格式字串 |

K／L／M 的「無」選項是為了避免表單分支：運動頻率選「無」時，工具自動把這三題填「無」。

## 藥物劑量的設計

劑量隨藥而異。若表單為 11 種藥各做一題劑量下拉，就得分頁分支 → 又踩回 `pageHistory`。
故表單只放一題簡答，**由 `index.html` 的 `DOSE_OPTIONS` 依所選藥物動態切換下拉**，
送出時組成 `藥名 + 空格 + 劑量`：

| 藥 | 劑量選項 |
|---|---|
| 無用藥／生活型態 | 無 |
| Mounjaro | 2.5／5／7.5／10／12.5／15 mg/週 |
| Ozempic | 0.25／0.5／1.0 mg/週 |
| Wegovy | 0.25／0.5／1.0／1.7／2.4 mg/週 |
| Saxenda | 0.6／1.2／1.8／2.4／3.0 mg/日 |
| Rybelsus | 3／7／14 mg/日 |
| Contrave | 1～4 錠/日 |
| Xenical | 120 mg qd／bid／tid |
| Jardiance | 10／25 mg/日 |
| Acarbose | 50／100 mg tid |
| 併用／轉換兩種 | **自由文字**（無法列舉，例：`Ozempic 1.0 mg/週 轉 Mounjaro 5 mg/週`） |

送出範例：`Mounjaro 7.5 mg/週`、`無用藥／生活型態 無`。

## 建表步驟

1. <https://script.google.com> → 新增專案 → 貼上 `tools/create-google-form.gs` 全部內容
2. 函式選 `buildAll` → 執行 → 授權（Forms／Sheets／Drive）
3. 看「執行紀錄」（Ctrl+Enter），把印出的 `FORM_ID` 與 `ENTRY` 兩段貼進 `index.html`
4. 確認表單與試算表已進「門診工具-正式運作中」；若搬移失敗會在紀錄裡提示，手動拖即可

## 回覆試算表的三個分頁

| 分頁 | 內容 |
|---|---|
| 表單回應 1 | 原始逐筆回覆 |
| 個案歷程 | 黃格填姓名＋出生年 → 該人每次回診的體重、腰圍、用藥劑量、與前次差、與首次差、累積減重%，附體重折線圖 |
| 個案總表 | 每人一列：回診次數、首次／最新日期與體重、總變化、累積減重% |

## 改欄位時的注意事項

- **不要在題目之間插入新題**：會改變回覆試算表的欄位順序，`個案歷程`／`個案總表` 的
  公式是寫死欄位字母（D＝體重、F＝BMI分級、G＝腰圍、N＝用藥、O＝劑量）。
  要加題就加在最後，並同步改那兩張分頁的公式。
- **選項字串一字不差**，尤其全形斜線 `／`。對不上 Google 會靜默丟棄那一題。
- 表單端一律不設必填，必填改在 `index.html` 的 `validate()`。

## 為什麼下拉裡沒有「手術」

官方 `normalizeDrug()` 有「手術」分類（`bariatric`／`GS`／`ESG`／`外科`／代碼 `7`），
2026_07 資料庫共 14 筆。**但手術個案在減重門診不需追蹤**（2026-08-18 使用者指示），
不屬於維持期回診工具的服務對象，故用藥下拉刻意不列這個選項。

曾經加過又撤掉，不要再加回來。
